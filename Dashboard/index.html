Welcome to the AI Recruitment & Workforce Analytics Dashboard. This end-to-end intelligence platform connects directly to the RecruitmentAnalytics SQL database and leverages a Random Forest predictive machine learning engine.

  • Source Conversion ROI: Track Employee Referrals vs. LinkedIn vs. Job Portals.
  • ML Predictive Screening: Uses evaluation metrics and candidate feature weights trained on 10,200 records.
